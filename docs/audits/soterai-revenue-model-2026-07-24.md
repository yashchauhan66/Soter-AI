## Revenue Models

### Model A: Self-Hosted Only (Conservative)
| Component | Calculation |
|-----------|-------------|
| Revenue | Monthly subscription per tier |
| COGS | ~$50/mo server + database cost per customer |
| Gross margin | ~85% |
| Customer acquisition | Founder-led, zero cost |
| Churn | ~10%/mo (early), ~5%/mo (stabilized) |

### Model B: Self-Hosted + SaaS (Base)
| Component | Calculation |
|-----------|-------------|
| Revenue | Self-hosted tiers + SaaS tiers |
| COGS | Self-hosted: $50/customer + SaaS: $200/infrastructure base |
| Gross margin | Self-hosted: ~85%, SaaS: ~70% |
| Customer acquisition | $200-500 blended CAC |
| Churn | ~5%/mo blended |

### Model C: SaaS-First (Aggressive)
| Component | Calculation |
|-----------|-------------|
| Revenue | Primarily SaaS tiers |
| COGS | Infrastructure + support at scale |
| Gross margin | ~70-75% |
| Customer acquisition | $500-2000 CAC (requires funding) |
| Churn | ~3-5%/mo |

2. **No VS Code Marketplace listing** — Blocks entire IDE use case
3. **No pricing page** — No self-serve conversion possible

9. **No SLA / support** — Enterprise buyers need contractual support

## Formulas Used

`MRR = Σ(Customer_Subscription_Amount)`  
`ARR = MRR_at_Month_12 × 12`  
`Gross_Revenue = Σ(Monthly_Payments_Received)`  
`Gross_Margin = (Revenue - COGS) / Revenue`  
`Churn_Adjusted_Customers = Starting_Customers × (1 - Monthly_Churn)^Months`  
`CAC_Payback = ARPA / (Monthly_COGS_per_Customer + Monthly_Sales_Cost_per_Customer)`  
`Break_Even_Customers = Monthly_Founder_Cost / (ARPA - Monthly_COGS_per_Customer)`  
`Cumulative_Revenue = Σ(MRR_Month_N × (1 - Churn)^N)`
