# Beta Onboarding Playbook

## Statuses
- **PAID** - Customer has converted to paid
- **ACTIVE_BETA** - Customer is actively using beta
- **FOLLOW_UP_LATER** - Customer needs follow-up
- **LOST** - Customer is not moving forward

## Onboarding Steps
1. Welcome email
2. Account setup
3. Integration walkthrough
4. Success criteria review
