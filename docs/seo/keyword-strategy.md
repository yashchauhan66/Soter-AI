## Keyword Research Methodology

Keywords are organized into clusters aligned with SoterAI's product capabilities, target audience, and market positioning. Each keyword includes search intent classification, target page mapping, priority tier, difficulty estimate, recommended content type, call-to-action, and internal linking strategy.

### Priority Tiers
- **P0** -- Must rank. Core product terms, highest commercial intent
- **P1** -- Should rank. Important supporting terms, strong traffic potential
- **P2** -- Nice to rank. Long-tail terms, lower volume but high conversion
- **P3** -- Opportunistic. Emerging terms, brand-building value

### Search Intent Types
- **Informational** -- User wants to learn (blog posts, guides)
- **Navigational** -- User looking for a specific product/page
- **Commercial Investigation** -- User comparing options (comparison pages)
- **Transactional** -- User ready to buy/sign up (pricing, signup)
