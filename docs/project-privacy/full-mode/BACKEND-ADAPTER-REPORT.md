**INFERENCE / limits:** The trusted owner-side deployment must protect executable/DLL/parent/configuration authority. The read/execute window, parent-directory races, administrator compromise, guest disk lineage, all host bridges and real effective network behavior are not covered by parser tests. This source component is not yet integrated into the extension VSIX or deployed as a service.

**INFERENCE / rollback:** Keep its enable callback false. To remove this source addition, remove only `WindowsBackend.mjs`, its test file and the new index export; preserve current evidence and the preceding controller source. No machine rollback or native-agent fallback follows from disabling this inspector.
