## What remains unprotected or untested

**FACT / observed failures (2026-10-12):** original file reads, hardlink/junction native reads, synthetic inherited environment/output, existing Git history and independent encoded/chunked delivery leaked through unmanaged routes in the retained survey. Source: [comparison](evidence/20261012-final-local/host-comparison.json).

**INFERENCE / design limits:** scanners cannot recognize all confidential prose or invented secrets. An approved ordinary file can retain private content; use always-masked classification or deliberate owner-reviewed publication. Native same-user extensions/processes can reach original buffers, tabs, clipboard and files. Original history, recovery files, copies and prior disclosures remain outside this bounded implementation. Shared local storage/keys do not establish independent custody.

**FACT / NOT_TESTED (2026-10-12):** actual Cline/provider uploads, independently enforced accounts/sessions/VMs, per-account mandatory egress, independent consent, durable policy signing/revocation continuity, real-service broker/DB operations, active remote-operation drain, parent-directory swap resistance, cross-platform isolation, administrator compromise, side channels and live unload/uninstall are not verified. Sources: [report JSON](../../packages/vscode-extension/verification/project-privacy-verification.json), [native limits](../../.tmp/pv-final/native/host-d8abee9e7e74adf6f85e0277/results.json), [architecture](ENTERPRISE-ARCHITECTURE.md), [I6 notes](ENTERPRISE-I6-PROTOCOL-NOTES.md).

**FACT / scope (local execution record, 2026-10-12):** no existing Code.exe was closed/killed/reloaded, no OS/account/VM/firewall/driver/hardware change was made, and no actual Cline or Claude Code model session completed; two public-context Codex/Gemini responses completed. The authorized verification hosts used isolated synthetic test workspaces and existing cached VS Code. Local source completion does not mean deployment, enterprise certification or completion of the full architecture.
