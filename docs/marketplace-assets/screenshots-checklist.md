# Screenshots Checklist

Required screenshots before marketplace submission:

- Dashboard overview showing aggregate security posture without real customer data.
- Integration wizard with API key guidance and server-side handling note.
- Browser extension popup in enrolled state without exposing device tokens.
- Browser extension warning/blocking state with redacted sensitive content.
- n8n node configuration showing credentials and guard operation fields.
- Workflow example showing input guard before an AI action.
- SIEM or webhook event view showing redacted audit payloads.
- Privacy/security settings or policy screen showing admin controls.

Screenshot rules:

- Use demo data only.
- Do not show real API keys, secrets, emails, customer names, or production URLs.
- Redact tenant IDs and event IDs unless generated for demo.
- Keep text readable at marketplace-required image dimensions.
