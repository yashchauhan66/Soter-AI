# SoterAI Guard - AI Security Scanner for VS Code

Short description:

Detect prompt injection, jailbreaks, secrets, PII, risky MCP tools, unsafe terminal commands, and AI context leaks directly inside VS Code.

## Safer Marketplace Description

SoterAI Guard is a developer-first AI security guard for VS Code. It helps scan prompts, selected text, current files, git diffs, MCP configuration, agent tool settings, and terminal commands before sensitive content reaches AI coding workflows.

The extension is local-first by default. It can detect common prompt-injection patterns, jailbreak attempts, secret-like values, PII including India-specific identifiers, suspicious AI instructions, risky MCP/tool permissions, and dangerous terminal commands. It also provides redacted copy flows, local activity ledger metadata, canary leak testing, and policy packs for common team postures.

SoterAI Guard is not a replacement for professional security review.
