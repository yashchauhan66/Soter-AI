# Information Security Policy

SoterAI operates security as defense-in-depth for company data and AI-agent actions. Controls include authentication, authorization, tenant scoping, redaction, audit logging, secure change review, and incident response.

## Requirements

- Production access must be least privilege.
- Secrets must not be committed to source control.
- Raw prompts, secrets, and tokens must not be collected in pilot telemetry.
- Security-sensitive changes require review and test evidence.
- Material incidents must follow the incident response process.

SOC2 compliance is not claimed. SOC2 readiness is in progress.
