# Incident Response Policy

## Severity

- P0: active breach, tenant isolation failure, data exposure, auth bypass.
- P1: high-risk security defect or prolonged outage.
- P2: contained bug or degraded service.

## Process

1. Triage and assign commander.
2. Contain impact.
3. Preserve logs and evidence.
4. Notify affected customers when required.
5. Remediate and verify.
6. Publish post-incident review for material incidents.
