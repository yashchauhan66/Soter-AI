# Phase 12 Pilot Onboarding Guide

## Welcome Flow

1. Confirm pilot owner, security reviewer, and engineering contact.
2. Create workspace and first project.
3. Create API key.
4. Run first scan in the playground or API.
5. Install VS Code Guard or Browser Guard.
6. Import n8n workflow if applicable.
7. Schedule a 30-minute feedback review after first usage.

## Quickstart Checklist

- Install VS Code extension: status Beta.
- Install browser extension: status Beta.
- Add JS SDK or REST API check: API Guard Stable.
- Run n8n workflow: status Beta.
- Create API key: required.
- Scan first prompt: required.

## Privacy Rules

- Do not collect raw prompts or secrets in pilot telemetry.
- Store metadata only: surface, counts, risk categories, durations, and boolean activation markers.
