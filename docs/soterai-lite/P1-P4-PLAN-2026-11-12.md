## Verification and claim rules

- Test the failing behavior before changing enforcement, and pair blocked examples with useful passing controls.
- Reuse code rather than duplicating scanner regexes or reviving inactive Full references as if they were deployed.
- Registered matcher relocation preserves its old import path via a re-export; no source file is removed.
- Hashes bind immutable bytes. A file scan is not a promise against later mutations or arbitrary undiscovered private data.
- Unsupported formats, missing daemon, invalid policy, stale evidence or absent approval fail closed.
- Docker installation alone is not isolation proof; inspect effective settings and execute canaries in the exact session.
- Do not read real credentials into tool/model output. Synthetic fixtures only for tests; real secrets belong in trusted runtime stores.
- Real AWS deployment, real-provider acceptance, five independent humans, and independent security/accessibility review need their actual inputs/evidence. Do not fabricate or waive them to mark P4 complete.
