## Deliberate local and external communications

- **Managed provider requests:** `BrokerManager.prepare` passes configured OpenAI/Anthropic/Codex/Gemini destination and provider key to the bundled broker. `GatewayPolicy.ts:94–120` validates destination/profile, assesses/canonicalizes a request, attaches upstream authentication and POSTs approved/inspected body to that configured provider, then buffers/inspects response. User text/code that survives the declared filters can reach that provider. `cloud.enabled=false` and `privacyMode=local` are **not** a global veto on this separate provider route. Empty destination/key withholds it. Requesters cannot simply choose an upstream in a body. Provider logging/retention is not controlled by Lite.
- **Dependency advisory lookup:** `dependencyGuard.osvMode=ask`. Owner-invoked Dependency Guard commands can offer OSV online lookup; the `always` setting permits lookup without another prompt, while `never` keeps these commands offline. `DepGuard.ts:202–216` and `DepGuardCore.ts:171–202` send package name/ecosystem/version to`https://api.osv.dev`; not source files. This does not run automatically in the inspected activation path. The MCP `checkDependency` tool calls offline heuristics only (`agent/toolLogic.ts:172–209`).
- **Local MCP/adapters/hooks:** `agent/mcpServer.ts` uses bounded stdio JSON-RPC; approved safe-read delegates to the live authenticated editor-owned127.0.0.1 bridge and returns exactly reviewed safe output. The caller receives that output and may itself send it elsewhere. Runtime access is not OS-verified agent identity; direct original-file reads remain outside this route. `PreCommitClient.ts:64–118` sends session/nonce/index-file metadata to its signed current local `/pre-commit` descriptor, not to a cloud service. Tool-specific command wrappers/bridges have their own bounded routes and must not be called universal shell/process mediation.
- **Owner app execution and explicit sharing:** Reviewed vault app/task/debug workflows inject selected values into the owned child environment; the application necessarily receives them and may have its own network behavior. Export/copy/report/public-snapshot commands create owner-selected local output that the user can later share. Ordinary browser support/rotation links are owner actions. Do not broaden local detector claims to arbitrary applications, other extensions, editor/OS telemetry or independent uploads.
