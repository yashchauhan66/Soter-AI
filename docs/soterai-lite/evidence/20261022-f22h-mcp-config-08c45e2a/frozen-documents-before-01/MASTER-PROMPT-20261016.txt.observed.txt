# SOTERAI LITE: BUILD, MAXIMIZE, TEST, RATE (single master prompt, maximum effort)

## MISSION
Split the project into two extensions and take the LITE extension to the highest coverage that extension-level controls can honestly reach.
 - SoterAI Lite (this task): every current non-VM feature, plus the upgrades below. Install the VSIX, run a 1-2 minute wizard. No admin rights,
   no VirtualBox, no controller service, no extra software.
 - SoterAI Full (VM isolation): scaffold only in this task; its code must not ship inside Lite.
Lite's promise: reduce exposure of project secrets (env files, keys, tokens, credentials) to AI tools that behave as documented but may
accidentally include anything readable in their prompts, requests and commands (the COOPERATIVE-AI model). Lite is NOT a boundary against a hostile or
manipulated same-user process; say this in the UI and docs. Never claim "perfect", "complete" or "unbypassable". The goal is a measured Lite Coverage
Score >= 80% for the supported tools, with every gate passing. If 80% is not reachable honestly, report the real number and why.

In L0 create docs/soterai-lite/LITE-CATALOG.json with >= 40 leak checks (IDs LS-01..), commit it and record its SHA-256. Later changes need a logged reason
and a new hash. Categories and minimum counts: file-read paths (8), terminal and environment (8), network and egress (8), git and history (4),

hostile-same-user sub-score and the old 10-scenario score with its arithmetic for comparability.
