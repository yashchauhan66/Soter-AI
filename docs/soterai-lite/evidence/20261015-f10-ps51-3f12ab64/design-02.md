# F10 clarification 02 — private boundaries before implementation

PUBLIC args are normalized operands: location/version/date `[]`, list `[relativeDirectory]` default `['.']`, sleep `[canonicalMilliseconds]` without its option token, write decoded literal args. Exact `$PSVersionTable.PSVersion` and `$env:NAME` forms are literal grammar exceptions before general `$` rejection; no expression is evaluated.

A missing vault is an empty registry only if there is also no pending, generation, issued source pointer or other retained vault recovery state. Missing/incomplete encrypted generations withhold; never decrypt an original recovery source as an output-registration fallback. Existing legacy unbound vault entries may be registered privately and conservatively for masking, but never injected into a terminal or returned as values. Current root-bound entries for the chosen project are registered completely within F07 limits. No current cipher/key creation for output filtering. Filter callback guards retain key/config/root/policy/cipher epoch checks; short registrations conservatively mask whole nonempty completed channels, with literal-safe replacement validation.

`registerProjectPrivacyCommands(context)` may return a trusted internal `{read(uri),revoke(),isEnabled()}` bridge wrapping its existing `managed-read-terminal` closure. It will not add a registered command letting external callers claim a native terminal identity. Extension activation passes that bridge to firewall registration, which shares its existing VaultManager with F10. Existing F04/F09 routes keep their behavior and are affected checks, not rewritten under this card.

Existing SafeGit's `execFile` timeout/maxBuffer path can terminate a child. F10 will reuse only its candidate/version/env/argument hardening helpers, not its execution/timeout helper. GIT metadata may be run by the finite fixed PS worker using a private extension-pinned Git descriptor with an empty external config/hooks directory. This trusted descriptor is prepared internally from existing standard install paths; it is not a request/command override. The fixed worker verifies Git>=2.36 before status/diff-stat and never invokes a supplied arbitrary executable or Git history/body form. If this private trusted descriptor is unavailable, Git metadata is visibly unavailable rather than a PATH or old-helper fallback. Worker PUBLIC API/fixtures remain unchanged; GIT extension gets its own fixtures before source.

No child is killed on timeout/cancel/overflow; actual child close and drained pipes remain the only completion proof. Fixed finite worker error completion may use ordinary PowerShell error propagation to return nonzero; it does not cancel/terminate another process. No arbitrary interactive shell/OS confinement claim.
