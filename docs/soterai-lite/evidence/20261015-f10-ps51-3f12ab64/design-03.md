# F10 private output filter contract, before fixtures and implementation

`VaultManager.createManagedOutputFilter(rootUri, enabled): Promise<ManagedOutputFilter>` is an internal API. `ManagedOutputFilter` implements the existing PowerShell51Output push/finish/cancel/dispose structural interface and adds `available(): boolean` for pre-launch admission. It exposes no values, keys, registration hashes, cipher or source content. Factory failure rejects with the existing constant vault-unavailable error; a filter that becomes unavailable withholds all output permanently, even after re-enable. No key or storage creation, no native value disclosure prompt and no original file/recovery-source decryption.

The exact root must be a current local workspace folder with no authority/query/fragment/alias; stable root identity, workspace membership, configuration epoch, runtime/key epoch, current raw policy files plus exported saved policy, enabled callback, vaultMode/secretMatching/outputRedactor/ps51Terminal machine flags and workspace trust/locality are bound. Existing ciphertext uses an already-existing twice-verified key. After decrypting the strict vault schema, include all legacy unbound entries and entries whose root is exactly this workspace URI; exclude other root-bound project entries. A partially bound entry (root without source or source without root) is unavailable, never silently omitted. Register all selected values within F07 limits; no partial/truncated registry. Final key/cipher/pending/root/policy checks occur after all awaits before returning the filter.

Missing current ciphertext allows an empty registry only when storage also has no pending record, issued source pointer, generation, mutation lock or leftover encrypted write record. Unknown `vault-*` entries count as incomplete recovery conservatively. Missing storage directory is allowed only after safe ancestor validation and stays bound to no vault/recovery records. Once current ciphertext exists, a missing/changed cipher or pending record revokes; there is no empty-registry downgrade. Checks retain normal concurrent public output-file creation (directory mtime is not an identity).

The filter delegates UTF8/control/bounds/encoding decisions to F08. With any nonempty registration shorter than eight Unicode scalars, conservatively mask every nonempty completed channel using `[REDACTED_SECRET_OUTPUT]`, and verify the combined replacement against all private registrations including short literal substrings. Invalid replacement withholds. Cancellation/disposal and guard false/throw/reentrant cancellation are sticky; no completion release after final guard revocation. Read-only private synchronous final guards may inspect bounded ciphertext/policy metadata and stable paths, never the original secret source.

Tests precede implementation: empty registry no key/storage writes; real encrypted current registry/raw+encoded masking; public positive control; short and marker collisions; missing key/cipher plus retained recovery; other-project exclusion and legacy inclusion; invalid/overbudget registry; pending/config/key/policy/root/cipher drift; cancellation; no original TextDocuments/UI/serialization leaks. Test values are synthetic only. These controls are LOW same-lineage, not independent certification.
