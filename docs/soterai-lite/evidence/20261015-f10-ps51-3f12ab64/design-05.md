# F10 native terminal registration and ownership, before fixtures/source

`terminal/PowerShell51Terminal.ts` exports Pseudoterminal class `(session)` with `open`, `handleInput`, `run(input:unknown):Promise<OutputResult>`, `close`, native `onDidWrite/onDidClose`. Session is a trusted CheckedPowerShellSession-compatible object, not command data. Hidden input, max4096 UTF8 bytes, no history or raw command echo; unsupported controls/overflow invalidate the WHOLE current line until enter (do not drop dangerous control characters then execute the remaining text). CRLF submits once. Backspace removes one Unicode scalar; help/clear are fixed local UI operations. One pending run; Ctrl+C clears/revokes and requests session cancellation. Close disposes session, but onDidClose waits for current run's actual completion; one-second unresolved notice may state STOP_UNCONFIRMED, never falsely claim child exit. Normal public completed output uses CRLF only after F08 normalization; withheld/exception emits fixed explanatory text, no error/command. Export a constant help string with Managed checks, declared commands and bypass limits. No other terminal interception claim.

`terminal/commands.ts` exports `registerCheckedPowerShell(context,vault,reader)` returning a controller `{status(),shutdown():Promise<void>,dispose():void}` plus module `stopCheckedPowerShell():Promise<void>`. Registration contributes PROFILE_ID and creates ExtensionTerminalOptions with owned pty, never a native TerminalOptions env merge. IDs `soterai.configureCheckedPowerShell`, `soterai.openCheckedPowerShell`, `soterai.runCheckedPowerShell`, `soterai.restoreCheckedPowerShell`, `soterai.checkedPowerShellStatus`. Configure/restore accept only a valid current root Uri or native folder selection. Run ignores command-like arguments and gets command text only from native showInputBox (password:true, ignoreFocusOut:false); no secrets in returned command metadata, only OPENED/RUN_REQUESTED/etc. Profile provider chooses current root; profile activation is optional. No ordinary user profile touched in tests.

Internal reader bridge returned from registerProjectPrivacyCommands is `{read(uri),revoke,isEnabled}`, using its existing managed-read-terminal closure. Extension activation passes it to registerFirewallCommands' optional third argument; absence withholds F10 instead of falling back to the public integration command. Existing firewall VaultManager instance is shared. Guard checks machine flag ps51Terminal plus matching/output/vault flags, workspace trust/local platform and bridge availability. Withdrawal cancels all live sessions and preserves stored profile/denies.

Value-free owned worker records use globalState key `soterai.lite.ps51.ownership.v1`: array<=64 of validated PowerShell51Snapshot records. Recovered rows always reported UNVERIFIED; never adopt or signal prior PIDs. Corrupt/nonarray/overlimit/duplicate/unknown/access-failing metadata withholds launches and preserves bytes. New session worker dependency adds optional `admitWorker(snapshot):Promise<boolean>` awaited before start, and `workerChanged(snapshot):void` on owned started/completed transitions; these are trusted internal only. Admission persists READY before spawn, rechecks session guard after await, and cancellation awaits no-child completion. Controller polls only its owned live snapshots for STOP_UNCONFIRMED, stores changed metadata only, retains at most32 terminal rows plus bounded recovered rows, coalesces serialized writes, and marks unavailable if persistence fails. shutdown requests cancellation then flushes latest safe ownership; it does not wait forever, kill or falsely resolve a child. Native tab may be removed by VS Code independently.
