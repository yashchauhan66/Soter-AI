## Strict descriptor and budgets

New host-free `packages/core/src/VaultAppDescriptor.ts`: export `parseVaultAppDescriptor(value:unknown): VaultAppDescriptor|undefined`, `VAULT_RUNTIME_LIMITS`, `vaultEnvironmentNameAllowed(name:string):boolean`. No thrown input-bearing errors. Deep-frozen valid descriptor has exactly `{schemaVersion:1,id,root,program,cwd,source,programDigest,args,selections}`. id is UUIDv4; root/program/cwd/source absolute normalized local filesystem paths, program/cwd/source lexically contained in root; program extension .js/.cjs/.mjs; programDigest lowercase SHA256 of the public app entry. VS coordinator separately verifies real paths/regular single-link files and identity; lexical parsing is not canonical ownership proof.

Selection exactly `{name,placeholder}`, name regex `[A-Za-z_][A-Za-z0-9_]{0,127}`, placeholder exact generated `[SOTERAI_PROTECTED_<32hex>_<ordinal>]` from F06. No value-derived vault ID/hash in descriptor/report. Names unique case-insensitively, placeholders unique, nonempty selections. Selected current records must match source/root/name/placeholder, with no ambiguous, legacy-unbound or non-env fallback. Source is an environment file supported by the private env model; current field values must equal the selected placeholders. Never load an arbitrary original .env as a fallback.

Reject case-insensitive loader/control names: PATH/PATHEXT/HOME/USERPROFILE/APPDATA/LOCALAPPDATA/SystemRoot/WINDIR/COMSPEC/TEMP/TMP/TMPDIR, NODE_* and ELECTRON_*; LD_*/DYLD_*; BASH_ENV/ENV/ZDOTDIR/PSMODULEPATH; PYTHON*/RUBY*/PERL*/JAVA*/JDK*/CLASSPATH; proxy names HTTP_PROXY/HTTPS_PROXY/ALL_PROXY/NO_PROXY and SOTERAI_* control names. Values are never descriptor fields or substituted into argv. Unknown fields/schema reject. Args are bounded literal strings: reject NUL/control, `${`, `$(` and backticks; shell=false always, no executable override, shell command, process option, freeform env or interpolation.

Export exact frozen `VAULT_RUNTIME_LIMITS={maxArgs:16,maxArgBytes:1024,maxArgumentBytes:8192,maxSelections:32,maxDescriptors:16,maxJobs:4,maxRuntimeMs:300000,stopGraceMs:1000,maxDescriptorBytes:32768}`. Path/id/text strings bounded before traversal; path max4096 UTF16 units. Descriptor JSON <=32KiB UTF8. F07 registration/value/total limits must pass before spawn, retaining all F08 output limits. Secrets that cannot be completely registered withhold launch. No partial selection/injection.

## Private vault lease

Extend existing VaultManager with internal runtime preparation/consumption, guarded by both vaultMode and machine `soterai.lite.vaultRuntime` (defaulttrue), local trust/provider constraints, root/source/policy/epoch and exact SecretStorage key. Public selection metadata only names/placeholders; source digests/identities and raw values stay private. Owner approves the exact descriptor and selected names before values are released. Recheck source/key/policy/root/program/cancellation after every held async step and immediately before spawn. Existing global pending migration blocks launch. Missing key/record, ambiguous name, stale placeholder or alias withholds, never regenerates/falls back to original. No plaintext source TextDocument, temp secret file or global `process.env` mutation.

Use a one-shot internal callback/lease, not a registered command returning raw env. Callback receives values only inside the trusted launcher stack; command/task/debug results contain metadata/sanitized completed output only. Values come from logical rawValue, never quoted replacementText. Keep every F06 migration/recovery guarantee and permanent deny. Subsequent withdrawal cannot recall values already inside app memory; request cooperative stop and withhold future output.

## Owned process and output API

New host-free `packages/vscode-extension/src/vault-runtime/VaultAppJob.ts` exports `VaultAppJob` and safe types. Constructor `(options:{descriptor:VaultAppDescriptor,values:Readonly<Record<string,string>>,runtime:{executable:string,electron:boolean},parentEnvironment:NodeJS.ProcessEnv,enabled?:()=>boolean},deps?:{spawn?:typeof import('node:child_process').spawn, setTimer?:(callback:()=>void,ms:number)=>unknown,clearTimer?:(handle:unknown)=>void})`. Trusted deps only for tests; no public command accepts spawn/runtime overrides. Actual coordinator fixes executable=process.execPath, electron=Boolean(process.versions.electron). Never search PATH. Use fixed bundled bootstrap source passed to Node `-e` plus literal app path/args, shell=false, windowsHide=true and piped stdout/stderr/private IPC; no new software/runtime or secret-bearing argv/files.

`start():Promise<VaultAppJobSnapshot>`; `snapshot():Readonly<VaultAppJobSnapshot>`; `requestStop():void`; `cancel():void`; `dispose():void`; readonly getter `completion:Promise<VaultAppJobCompletion>`. Snapshot exactly safe `{id,state,pid?,exitCode?}`; state union `READY|BLOCKED|RUNNING|STOP_REQUESTED|STOP_UNCONFIRMED|EXITED|STOPPED|CANCELLED`. Completion `{snapshot,output:OutputResult}` uses F08 result. Private fields do not serialize values/env/chunks. Start single-use; guards/cancel before actual spawn prevent it; Node spawn errors finish BLOCKED with withheld output. No raw exception messages or commandline in UI/audit.

Build a fresh child env from the existing minimal OS/locale/temp allowlist, validating allowed path/locale strings, excluding inherited credentials/home/search/preload/proxy values. Inject only exact selected names with string non-NUL values; fail before spawn on extra/missing/case-colliding/reserved values or matcher budget. Set ELECTRON_RUN_AS_NODE=1 only for Electron runtime. Never alter parent env or reuse its object; sibling managed launches without selection inherit none of these values.

F08 accepts stdout/stderr bytes; no data event is emitted to task/debug/UI before actual close and EOF. Always drain both pipes, including after output overflow/cancel. Overflow/guard withdrawal/timeout permanently withholds output and requests cooperative stop, without accumulating discarded data. Snapshot callbacks are not necessary; integration may await completion and inspect safe snapshots. Successful/nonzero natural close returns actual exit code plus filtered output; cancellation returns no undecided output.

## Cooperative stop and crash

Bootstrap unrefs its private IPC channel and loads the selected entry normally (CommonJS require or ESM import). Optional exported `start(signal:AbortSignal)`/`stop()` supports cooperative app shutdown. STOP IPC only aborts/calls that contract; never executes a supplied expression, calls child.kill/TaskExecution.terminate, force-exits or adopts an unrelated PID. Ordinary finite scripts work without this optional hook. Actual child close plus drained stdout/stderr is the only exit proof. ACK is not proof. After stopGraceMs an unclosed child remains visible STOP_UNCONFIRMED; never resolve completed job/close pseudoterminal silently while it lives. Timeout maxRuntimeMs similarly withholds and requests stop; no force kill. Deactivation requests stop and retains value-free ownership metadata; after restart report prior live/unknown jobs as UNVERIFIED, never auto-adopt/kill by PID.

Actual synthetic negative child may ignore STOP but must self-exit shortly for cleanup; assert STOP_UNCONFIRMED before its natural exit. Tests may use mock child events/timers for indefinitely running cases. Do not create a stranded real process or terminate it externally.

## IDE integration and honest capabilities

New registration module `vault-runtime/commands.ts` shares existing VaultManager via firewall registration. Native owner configuration selects public app + migrated env and names; stores only strict descriptor metadata in extension workspace storage, max16. No `.vscode` secret files/config rewrites. Saved public program digest is allowlist-bound; a changed app requires review again. Every run gets a fresh native modal showing program/cwd/arguments/selected names and the warning that selected app code can inspect/write/print/transmit its injected values. Same-user owner UI is not agent-proof. Cancellation/stale snapshots prevent spawn.

Commands configure/run/stop use opaque descriptor/job IDs only, no raw values in returns. A CustomExecution TaskProvider uses descriptor ID only; raw env never enters Task/ProcessExecution options (which merge inherited env). An owned inline DebugAdapter provides launch/configurationDone/output/terminate/disconnect lifecycle through the same coordinator. Advertise no breakpoints/evaluate/readMemory/setVariable/source-level debugger support, reject those requests and label the session lifecycle-only. This is a real owned session/task surface tested via mocks/native callbacks, not a claim of full Node debugging. No raw env in debug config/adapter options or observer-based redaction claims. Source-level debugger attachment is outside this scoped card and remains an explicit limitation.

Feature withdrawal blocks new launches, requests cooperative stop of owned jobs and withholds their pending output; saved denies/ciphertext remain. Task/debug close must await actual child close, or visibly retain STOP_UNCONFIRMED. Native health/report strings contain names/counts/statuses only.
