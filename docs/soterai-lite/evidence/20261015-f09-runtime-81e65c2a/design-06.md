# F09 clarification 06 — conservative output for short selected values

F07 intentionally recognizes 1–7 scalar registrations only as whole explicit parts/decoded semantics. That is insufficient for an app that embeds a known short credential in a longer stdout line. F09 must not claim such a line is safe. Preserve F07/F08 contracts/source: when any selected app value has fewer than eight Unicode scalars, conservatively mask **every nonempty completed app output channel**, even public output, rather than attempt ambiguous short substring classification. Validate the fixed replacement using the actual private registry, including all short literal substrings; a marker collision withholds the result. App execution still receives the exact selected value. Empty channels remain empty. Output errors/limits/cancellation still withhold; no release precedes actual close and EOF. A paired >=8-value public-output fixture retains normal availability.

This is a declared F09 availability tradeoff for short values, not a new matcher guarantee or output limit bypass. New fixture is being authored before the production change. Native fixture uses a long fake URL and remains unchanged. Native app behavior/dependency/side-effect and external-upload limitations remain.
