# F15a fixture limits before production

Pure decodeBoundedJson(Uint8Array, overrides) returns frozen body and canonical JSON. Default1MiB input/32 depth/8192 tree nodes/64KiB decoded UTF8 per key or string; nodes include keys and values, object root depth0. Exact boundaries accepted, overflows rejected, overrides validated positive bounded integers. Reject unsafe integer numbers in addition to nonfinite values, preventing silent numeric identifier rounding; ordinary finite decimals/exponents remain supported. Duplicate escaped keys rejected case-sensitively, prototype-named keys inert null-prototype data, no lone surrogates. A leading BOM is rejected, a BOM inside a valid string preserved. Body read deadline is actual elapsed read time, not an assumption about Node server periodic timeout enforcement. All errors constant/no body fragments. Wire fixture cleanup closes only owned HTTP sockets/servers, never processes or fixture directories.
