This evidence-only successor retains the original four on/off deterministic coding tasks and fake DB/API oracles. It binds a newly qualified artifact and source proof before loading only the five declared pure product components. It never converts their results into installed-product or per-tool acceptance.

The Node project executes installed Express 5.2.1 routing with actual Node IncomingMessage/ServerResponse objects over a bounded in-memory Duplex. Existing public Express files and dependencies are hash-pinned; no package installation or root dependency change is needed. This is actual Express framework execution, without a listening server or TCP claim. Next uses the existing real NextRequest/NextResponse classes with fake API data, without a Next server/build claim.

Run only after current-package-qualification is accepted. Create `v02-current-binding.json` with exact `{qualification, sourceProof, expressProof}` file facts, then invoke `node run-scripted-benchmarks-current-01.cjs --run v02-current-binding.json SHA256`. The runner verifies binding/artifact/source/runtime input identities and rechecks them after completion. It creates a unique evidence directory and retains synthetic task before/after files, controls, scripted completions/prompts/interruptions/time, and explicit zero-model-call labels.

Child process, network, server and fetch calls are guarded during task execution. The four cases must preserve useful public output, withhold the fake secret on the protected path, show the intentional off-path synthetic leak oracle, refuse invalid service inputs and omit private service fields. Whole secret-bearing diagnostic channels remain masked, including their surrounding public text; a separate clean completed output proves useful output is retained.

Actual authenticated agents, natural developer behavior and per-tool 44-row acceptance remain separate requirements. These scripted cases do not produce a final rating or independently reviewed status.
