## Release model and API

`packages/core/src/StreamingOutputRedactor.ts`, exported from core/index. `new StreamingOutputRedactor(values: readonly string[], options?: {enabled?:()=>boolean})`; `push(channel:"stdout"|"stderr", bytes:Uint8Array): {status:"BUFFERED"|"WITHHELD"}`; `finish(exitCode:number): OutputResult`; `cancel():void`; `dispose():void`. Result `{status:"COMPLETE"|"WITHHELD",stdout:string,stderr:string,redacted:boolean,exitCode?:number,reason?:string}`. All returned objects are frozen, safe metadata before finish; WITHHELD always has empty stdout/stderr, redacted=false, constant value-free reason. Private states never serialize. No callbacks receive input chunks. Default enabled=true for host-free consumers; actual singleton guard starts false until machine flag binding.

This is a **completion-buffered stream processor**: accept byte chunks incrementally, release no undecided prefix/tail before successful final flush. It is not a live interactive passthrough. This prevents a late chunk/error from making previously released text unsafe, while keeping public completed output useful. Long public output within the budget is preserved. Overflow/cancel/invalid final UTF-8/control syntax withholds the entire operation, without raw fallback. No claim that arbitrarily large/infinite streams remain available. Shell consumers must show their bounded completed result; independent uploads and arbitrary native terminals are outside this card.

Each instance owns two separate fatal UTF-8 decoders and control-parser states. Interleaved channels cannot complete each other's UTF-8/ANSI sequences. No singleton stream history. A pending scalar may span any number of chunks in its own channel. Treat each push synchronously; caller mutation after push cannot alter retained data. Empty chunks are legal. After finish/cancel/error the instance is terminal; later calls withhold and cannot replay or revive values. Nonzero signed32-bit exit codes still return successfully sanitized output with the actual exit code; malformed exit metadata withholds.

## Plain text normalization

Release plain text only. Preserve ordinary Unicode exactly, including BOM; no case/NFC/NFKC folding. Preserve LF/tab, normalize CRLF to LF across chunks. A bare CR, backspace, DEL, unsupported C0/C1 or bidi cursor/control rewriting withholds rather than simulating terminal editing.

Remove complete CSI SGR sequences (`ESC [` or U+009B, parameters `[0-9:;]*`, final `m`) with at most128 UTF-16 units per sequence. Remove complete OSC sequences (`ESC ]` or U+009D) terminated by BEL, ESC-backslash or U+009C, at most4096 UTF-16 units per sequence; no OSC payload/title/clipboard/hyperlink bytes reach the sink. Unsupported ESC/CSI operations, malformed/unterminated controls or any incomplete UTF-8 final flush withhold the whole result. ANSI insertion between Unicode scalars and every chunk boundary is supported; insertion inside a UTF-8 scalar is invalid and withholds.

## Matching and fixed bounds

Reuse F07 exact/encoded/provider/entropy recognition on three explicitly defined views of the normalized operation: stdout, stderr, and normalized pieces in decoder-emission arrival order, plus stdout followed by stderr as the output consumer's explicit ordered group. Duplicate views may be deduplicated. No arbitrary permutation, whitespace removal or joins across operations. Any MATCHED view masks each nonempty output channel entirely as `[REDACTED_SECRET_OUTPUT]`, preserving no matched fragments; public negative controls preserve normalized stdout/stderr exactly. Any matcher WITHHELD withholds the operation atomically. JSON protocol-leaf grouping remains in existing OutputFilter; this byte processor does not recursively parse arbitrary protocols.

Export frozen `STREAM_OUTPUT_LIMITS` exactly `{maxInputBytes:131072,maxOutputBytes:131072,maxChunks:4096,maxSgrLength:128,maxControlLength:4096,maxExpansion:32}`. Raw bytes across both channels count before decoding; maxChunks counts every push including empty chunks. All limits inclusive. Normalized/output UTF-8 bytes are bounded; output expansion must also be <= max(64, rawInputBytes*32). F07's existing limits still apply; do not silently bypass them. Control string length includes introducer/terminator. Reuse one matcher instance per operation. No source values/hashes/snippets in reasons or progress metadata.
