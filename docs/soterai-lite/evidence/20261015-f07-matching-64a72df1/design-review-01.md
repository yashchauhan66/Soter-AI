# F07 planning review 01

Same-lineage independence **LOW**. Read-only planning against the frozen F07 row and existing detector/model interfaces. No production changes, fixture execution, native host or real-secret reads. This new note does not activate F08 streaming or F16 gateway behavior.

## Recommended contract to freeze before fixtures

- **Registered values:** preserve exact case, whitespace and Unicode representation. Do not NFC/NFKC normalize, lowercase, trim or strip punctuation. Reject unsupported lone-surrogate registry entries. A registered test-looking/low-entropy value must not be suppressed by generic placeholder or example heuristics. For short values of 1–7 Unicode code points, recognize an entire explicitly grouped value/request part or an explicit credential-value context; withhold any claim of arbitrary short substring recognition. Empty registrations are invalid. State the short-value policy in the API and tests.
- **Transforms:** define one layer only. Base64/base64url operate on UTF-8 bytes, with strict alphabet, padding and canonical round-trip rules. Hex accepts even-length bytes and either hex case. URL decoding normalizes percent-hex case only; explicitly decide whether form-style plus means space. JSON escaped/quoted forms must use valid JSON string semantics, including surrogate pairs, escaped backslashes and quotes. Encoding syntax normalization must never change decoded secret case or Unicode. No recursive transform chain, arbitrary cipher, executable expression evaluation or universal private-prose claim.
- **Mixed encodings:** specify whether partially escaped URL/JSON values are supported; a canonical-only generated-variant implementation must not advertise all mixed escaping. Strict candidate decoding with bounded source-span mapping can support mixed escaping, but malformed input must not be silently repaired with replacement characters. Keep source offsets in one declared unit, preferably JavaScript UTF-16 offsets, and preserve request-part coordinates for every match.
- **Concatenation:** join only an explicit ordered request-local group supplied by the caller. No permutation, arbitrary subsequence search, whitespace removal, inserted separators, joins across unrelated metadata channels, or state retained between calls. Validate the combined representation consistently when a Unicode scalar straddles string parts. Split-message recognition is distinct from the byte-stream/chunk handling reserved for F08.
- **Provider/entropy findings:** keep registered, provider-shape and entropy reasons separate. Reuse declared provider patterns and their false-positive controls. A useful conservative entropy starting point is an ASCII credential-value candidate of 32–512 characters, Shannon entropy at least 4.3 bits/character, at least three character classes, and an explicit credential field/assignment context. Freeze exact formula, alphabet, inclusive boundaries and context grammar. Random prose, UUIDs, lockfile checksums, ordinary URLs and identifiers must not become findings merely for being long. Those generic negatives must never override an exact registered match.
- **Bounded work:** a practical initial envelope is 128 distinct registrations, 4096 UTF-8 bytes per value, 64 KiB total registered bytes, 32 request parts and 256 KiB total request bytes. Cap derived representation storage separately, for example 2 MiB and 16 variants per value; bound decoded candidates, output matches and search work too. These numbers are proposals for root's pre-fixture freeze, not existing implementation behavior. Exceeding a declared budget must produce a typed unavailable/incomplete decision, never a clean/no-match result. Do not partially initialize a registry while implying all registrations are protected.
- **Safe results:** expose opaque registration ids, reason and source spans only; no raw values, decoded candidate text, value fragments or value hashes in reports/errors. Do not collect environment or file values automatically as part of this host-free matching card. Feature withdrawal must be explicit to callers and preserve existing F01–F06 denies/masks.

## Meaningful controls

Use paired positives/negatives at every frozen threshold; multibyte UTF-8 and canonically equivalent but unequal Unicode; case changes; short values in prose versus exact credential values; malformed base64/hex/URL/JSON; mixed escaping according to the chosen contract; every request-part split of representative synthetic values; independent calls that must not combine; overlapping/duplicate registrations; expansion, candidate and match-budget exhaustion; and bounded property/fuzz checks with fixed seeds. Assert safe metadata and correct original-part spans as well as the detection decision. No result here certifies an external tool, streaming sink, network gate or universal secret detection.
