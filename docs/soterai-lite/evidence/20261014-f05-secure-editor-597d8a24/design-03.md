Synthetic diagnostic01 establishes this; normalize only Windows dev to0 while retaining inode, creation/modification/size, canonical root and digest checks. Commands02 then15PASS1FAIL: serializing CustomDocument edit events included private model text. Metadata-only CustomDocument.toJSON corrects this without weakening sink assertions.

Read-only review LOW identified further integration regressions; test author adds frozen C17+ before fixes. Rotate per-view operation session on every hide/revoke/split/source/config event; outgoing owner-value messages carry session/revision and the script verifies them. Pending native confirmations cannot survive a revoked session. Source watchers clear reveals immediately. Bound original/ciphertext reads at descriptor level, not merely a pre-read stat.

SaveAs binds source identity/digest/revision before and after native review, then exclusive destination creation and canonical/regular/nlink/digest/trust/cancellation checks after fsync before reporting success. Source drift refuses export. Association writes retain a pending receipt on apply-then-throw, verify relevant actual mappings and only remove undo receipt after verified restoration; unrelated mappings remain.

Implicit edit/undo/save recovery generations must be discoverable: per-generation issued metadata includes kind and creation time. Opening without a workbench backupId offers native owner selection of the latest issued implicit draft, never writes the original automatically. Successful durable save/revert releases only this document's current implicit recovery; replacement first durably issues its new generation then releases prior owned implicit recovery. Native backups remain until their returned delete callback is called. Failed writes keep their last encrypted draft selectable. Bound retained generations to128 per source and refuse additional unowned/unrecoverable writes at the limit; no destructive cleanup of evidence or other generations. Metadata contains no secret values or key bytes.
