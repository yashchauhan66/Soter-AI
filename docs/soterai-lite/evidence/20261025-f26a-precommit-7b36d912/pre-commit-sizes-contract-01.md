The expected request is a plain finite1..128-element array of unique40-lowerhex SHA1 OIDs in caller order. This matches the nonempty real `PreCommitGitProcess` sizes request. Empty staged trees skip sizes/batch; an empty size request is unavailable. Reject runtime lookalikes, proxies, accessors, sparse arrays or coercion hooks without invoking caller code. Do not mutate caller bytes/identities.

Admit only actual Buffers up to12,288 bytes and decode fatal UTF8. The entire response is exactly one LF-terminated `<expected40lowerhex> blob <canonical decimal>\n` row per requested identity in that order. Decimal is `0` or a nonzero digit followed by digits, a safe nonnegative integer. Each size <=65,536; sum of unique requested sizes <=1,048,576. Return frozen array/records with only oid/size. Unknown/reordered/duplicate/missing/trailing rows, other object types, `missing`, CRLF/tabs/extra spaces/BOM/NUL, malformed UTF8, noncanonical decimals, bounds or input-admission failure return undefined for the whole response. Never return a valid prefix or input-bearing exception.

This parser establishes framing only, not Git, index, blob-body or commit authority. Whole staged-tree budgets count raw sizes PER PATH before dedup in the separate scanner, so repeated OID paths cannot evade its1MiB limit. Body SHA1/framing, live owner validity, effective index identity, final release and actual child close/EOF remain separate gates.
