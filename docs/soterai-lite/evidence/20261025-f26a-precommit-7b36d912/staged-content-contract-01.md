This contract is one component of the existing F26a card; it creates no hook installation, index identity or commit permission.

API: `inspectStagedBlob(source: string, raw: Buffer): Readonly<{ status: "CLEAN" | "CANDIDATE" | "UNAVAILABLE" }>`. Return exactly one ordinary status data property. No paths, snippets, values, matches, references, line numbers, exposure findings or ledger fields leave this private component. Do not throw input-bearing diagnostics, coerce caller objects, mutate the input Buffer, retain private request state, perform I/O, follow references or execute source/configuration. Runtime freezing is not prescribed by these tests.

`CLEAN` means complete admitted private analysis found no heuristic candidate. `CANDIDATE` means the complete admitted blob has a heuristic candidate. `UNAVAILABLE` is the required withheld outcome for invalid input, unsupported grammar/expression/schema, ambiguous or incomplete parsing, raw/decoded text hazards or exhausted canonical work. A matching prefix cannot override a later unavailable condition. These statuses do not validate a credential, prove registered-value coverage or authorize a Git operation.

Admit actual Buffers only, with an inclusive 65,536-byte raw cap and fatal UTF8 decoding. Preserve useful empty/public text, ordinary Unicode, HT, LF and CRLF. Refuse unsupported C0/C1 controls, DEL and Bidi_Control characters in raw or decoded semantic text; refuse malformed Unicode/lone surrogates. No repair, truncation or partial prefix result. The exact64KiB controls use public punctuation/multibyte text to avoid conflating the byte cap with independent matcher work limits. Separate repeated quoted public strings exercise the existing canonical matcher withholding budget.

Source identity is a private bounded canonical project-relative path, without NUL/control/Bidi, absolute/drive/UNC paths, backslashes, empty/dot/dot-dot components, Windows stream/device aliases or trailing dot/space. Overlong paths are unavailable. Unknown runtime source/blob types are unavailable without coercion. This component receives no caller-selected filesystem location to open.

Format selection uses current canonical APIs, with specialized fixed families before broader JSON/YAML/generic handling:

- Generic plain `.txt`, `.md`, `.log` and extensionless paths, including `.gitignore`, use the existing canonical `RegisteredSecretMatcher([])` provider/entropy/supported single-layer encoding semantics. Empty registrations deliberately promise no arbitrary registered-value recall. A low-entropy opaque literal is a CLEAN negative here; a canonical credential-context entropy fixture is CANDIDATE. Canonical WITHHELD always maps to UNAVAILABLE.
- Dotenv basenames `.env` and `.env.*` retain canonical dotenv credential-name context and exact public/template controls. Dotenv selection precedes the generic extensionless rule.
- JS/JSX/TS/TSX/MJS/CJS follow `sourceSyntaxForPath` and the matching fixed source parser through existing hygiene analysis. Static low-entropy password/API-key declarations and decoded escaped literals are candidates. Supported public code and direct `process.env` references remain clean. Credential computations, calls, mixed interpolations and malformed source are unavailable; no evaluation or raw clean fallback.
- Saved JSON uses the actual strict canonical JSON/service-account analysis. Decode names and string values; duplicate decoded fields, nonfinite numbers, unsupported credential schema and malformed/trailing content are unavailable. Ordinary public key identifiers, public PEM, templates and placeholders retain their canonical negative outcomes.
- Fixed config families reuse their actual path selectors and complete canonical parsers: container/Dockerfile, Terraform native/JSON, registry npmrc/pypirc, CI YAML, editor JSONC and project MCP JSONC/TOML. Preserve parser precedence: CI before broad container YAML, editor/MCP/Terraform JSON before broad JSON. Arbitrary foreign YAML is unavailable under the canonical schema restriction; unknown `.py`, `.sh`, `.rs`, `.wasm` and `.bak` formats are unavailable, including when their raw text contains a provider token. Do not invent a new regex parser or downgrade a known parser failure to generic clean matching.
