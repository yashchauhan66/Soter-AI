# F26a finite client test contract

TEST ONLY, prepared within the existing F26a design before the corresponding client implementation. Root must capture the actual missing-module baseline before production. No replacement plan or feature, native, compiler or behavior completion claim.

Announced API: `runPreCommitClient(rawPin:Buffer,indexPath:unknown,options?:{runtime?:string,worker?:string,now?:()=>number,request?:(endpoint:string,rawRequest:Buffer,deadline:number)=>Promise<Buffer|undefined>}):Promise<'ALLOW'|'BLOCK'|'UNAVAILABLE'>` in `history-hooks/PreCommitClient.ts`. Runtime/worker/clock/request options are private test seams. The eventual bundled native entry accepts reviewed pins/index data and takes no such invocation overrides. Defaults and real native HTTP remain later root gates.

The raw reviewed pin uses the exact current `PreCommitHookText` schema: version, captured root, installation generation, canonical Ed25519 public key, exact worker/runtime paths and SHA256 hashes, descriptor path and systemRoot. All test files are ordinary retained synthetic files under a newly created synthetic root. The Code.exe fixture is inert text and is never executed. The synthetic worker is also never imported/executed. Roots contain manually framed SHA1 DIRC indexes; `prepareCheckedHookIndex` establishes genuine root-bound fixture metadata and `captureHookIndex` supplies the exact selected-index digest/identity witness. Only real Ed25519 descriptor/decision framing is reused.

All requests use the injected fake seam. The endpoint is numeric IPv4 loopback metadata with no server/listener/network creation. The fake captures and parses each actual request body, and signs an actual decision for its fresh request nonce and the selected initial index snapshot. No child, Git, process signal, real credential/profile, file deletion or native runtime is involved. Before mutation, old bytes are retained at unique sibling names. Atomic replacements are constrained inside their exact root and explicitly prove a changed file identity.

Twenty declared tests cover:

- Complete unchanged public ALLOW, exact default `'.git/index'` request for undefined selector, bounded whole-operation deadline, reviewed caller buffer preservation and unchanged observed worker/runtime/descriptor/index bytes.
- Fresh nonce per invocation, exact canonical request schema and no staged body, finding, filename, environment or public-key fields. An unstaged synthetic private worktree does not replace public staged data.
- Genuine explicit relative and absolute alternate-index selection. Explicit empty, invalid, missing or outside selectors refuse without a request/default/worktree fallback, as confirmed by root before freeze.
- Malformed/noncanonical/duplicate/UTF8/BOM/oversized pin refusal, schema/path/version/hash/key controls, exact invocation paths despite same-byte siblings, and missing/changed initial artifacts.
- Descriptor signature and captured root/generation/worker/runtime bindings, malformed/framing/8192-byte refusal and an unauthenticated external-endpoint mutation, all before any request.
- Useful correctly bound signed BLOCK. Signed BUSY/UNAVAILABLE, absent response or thrown transport failure become UNAVAILABLE. Incorrect decision root/generation/session/nonce, wrong selected-index hash/identity for either ALLOW or BLOCK, foreign/forged/malformed/oversized signature frames and prior-nonce replay all refuse.
- After request await, exact final synchronous index bytes plus identity, descriptor bytes plus identity, descriptor restart/session change and worker/runtime bytes plus identity must still match the captured initial witnesses. Byte-identical atomic replacements are distinct drift controls. Final index drift revokes both a held ALLOW and a held BLOCK classification.
- A mutable monotonic test clock stays at1000 until the request callback completes, then moves to the exact deadline61000, beyond it, backwards or nonfinite. All refuse; nonfinite initial time admits no request. No assertion relies on an implementation-specific count of clock samples.
- Inclusive worker2MiB cap with actual pinned ordinary files:2097152 bytes may complete;2097153 bytes refuse before request. Descriptor cap uses8193 actual bytes. The512MiB runtime cap is reserved for implementation/static review, as agreed with root; no huge file is allocated solely for a cap fixture.

ALLOW requires every artifact/path/hash/signature/current descriptor/nonce/session/index binding and final deadline recapture to pass. BLOCK is returned only for a valid current signed binding; failed or stale authority is UNAVAILABLE. The tests require fixed string results and never raw response/error fallback.

These are unit seam tests with retained filesystem races, not actual HTTP/native or owner Git invocation evidence. They do not prove atomicity across final-check-to-Git, same-user exclusion, installer recovery, absence of all unobserved filesystem reads/writes, registered-value coverage, protection against hook removal/`--no-verify`, or F26a completion. Existing root full/compiler/new VSIX/native/withdrawal/commit byte barriers remain required.
