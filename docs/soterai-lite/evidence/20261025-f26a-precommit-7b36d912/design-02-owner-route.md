# F26a owner route decisions

Existing F26a / U7-U8 / LS-27 component design, not a replacement plan. PREPARED, no service/worker/native claim. Root alone implements production; tests/reviews parallel, LOW independence. Parser32 and compiler01 PASS already recorded separately.

Use a **live owning-editor service**, separate from SafeReadBridge. A copied setting, installer-time boolean or expiring heartbeat cannot supply current machine-flag authority. New restricted machine flag `soterai.lite.historyHooks.preCommit`, default false; repository overrides cannot opt in. Installed hook blocks clearly while its owning editor/session is absent or disabled; reviewed Restore removes it. Status never calls an unavailable owner protected. No standalone registered-value promise: use canonical provider/entropy/encoding and supported source/config hygiene parsers with an empty registration set.

The fourth packaged runtime is a minimal finite hook client. Canonical staged analysis stays inside the owner extension. No `vscode` import in that client. Build/provenance/content inventories must deliberately cover all four runtimes; no silent transfer of previous three-runtime claims.

## Authority and wire

After native review, create an installation UUID and durable Ed25519 signing key in SecretStorage. Private key and encrypted original-hook backup stay in SecretStorage/private encrypted storage; no private signing material, bearer or registered values in hooks, argv, environment or descriptor files. Hook configuration pins the public key, captured root, installation generation, fixed installed runtime/worker paths and their reviewed hashes. A public endpoint descriptor is signed by that key and updated on owner restart. The worker takes its root/key/generation from the reviewed hook invocation, never a descriptor/request-selected root or cwd.

Bind the HTTP server to `127.0.0.1` on an OS-assigned port, fixed POST `/pre-commit`. Validate exact Host, JSON content type, no Origin, method/path and size before admission. Header/body/connection/deadline caps, one active operation and no waiting work queue; BUSY creates no Git child. Endpoint authentication is response authentication, not caller identity: same-user callers remain unverified and cannot select another root or obtain raw content. Connection/body failures return a fixed unavailable result. No redirects, proxy/URL fallback or external host.

Use distinct signature domains for endpoint descriptors and decisions. Strict finite exact JSON schemas, duplicate refusal, bounded fatal UTF8, new random request nonce, installation and owner session binding. The response contains only fixed status, nonce/session/generation and captured index digest plus identity digest; never filenames, blob text, matches or snippets. Worker verifies the pinned key, signature/domain, current descriptor/session, nonce and exact requested index identity. A forged endpoint may refuse service but cannot produce a new signed ALLOW.

`indexFile` is untrusted path data from Git, not authority. The owner resolves it only inside the captured ordinary `.git` directory. Undefined selects the default index; an explicitly invalid/missing index never falls back. A new async CheckedHookIndex factory internally calls canonical prepareCheckedGitMetadata for that exact root, then validates the selected v2/v3 SHA1 index, regular stage0 entries, safe paths, bounded extensions/size and exact file/ancestor identities. Its opaque aggregate capability is immutable and sticky on index/root/metadata/policy/flag drift. A caller-provided descriptor cannot be borrowed from another root.

Finite private Git children use validated captured `GIT_INDEX_FILE` and canonical safe environment/options, with hooks/fsmonitor/conversion/credentials/network/lazy-fetch disabled. Operations are fixed version, stage listing, object-size metadata and exact-object batch. No arbitrary Git args, worktree body fallback or staging. Compare listing entries with the validated effective index; full staged tree <=128 entries, <=64KiB/blob, <=1MiB admitted raw, <=256KiB listing, <=8KiB stderr, <=60 seconds. Unknown/binary/cap/parser failure is UNAVAILABLE, never partial ALLOW. Preserve each path context for shared blobs and verify body size/type/SHA1. Charge admitted raw before failed decode.

At final signature, recheck live owner flag/root/policy/installation/index and completed analysis. Worker synchronously recaptures the **same ordinary index identity and bytes**, verifies signature/session/nonce, and sets its exit code with no further await. A completed held ALLOW must be revoked on every tested withdrawal/drift point. The remaining final-check-to-Git-commit race and deliberate same-user hook removal/`--no-verify` remain explicit cooperative limits; this is no atomic OS boundary.

## Launch, coexistence and recovery

The fixed hook prefix invokes the pinned Git distribution `env.exe -i` by absolute quoted path, then the pinned installed Code executable in Electron Node mode and the exact packaged worker. Clear startup preloads **before** Node starts; never merge ambient credential/PATH/NODE_OPTIONS/NODE_PATH values. Pass only fixed OS paths, Electron Node mode and reviewed literal arguments. Capture `${GIT_INDEX_FILE-.git/index}` as quoted path data before clearing the child's environment; explicit empty is invalid. The original hook's own environment and arguments remain unchanged.

For a supported ordinary bounded UTF8/LF `#!/bin/sh` original, insert the finite prefix immediately after its unchanged shebang and preserve its remaining bytes at the same path. Scanner success falls through exactly once; failure exits before the original body. No plaintext sibling backup. Refuse unsupported interpreters/flags/links/ambiguous effective hooksPath rather than silently replace a framework or write an unused default hook. Test actual default and supported in-root custom core.hooksPath invocation; owner commit must not force an empty/per-command hooks override.

Review precedes key/backup/write/service creation. Encrypt and read back the original/absence plus applicable mode; persist PREPARED before mutation; recheck generations; exclusive/guarded write and readback; APPLIED only after verified success. Restore/rollback only exact owned bytes. Owner edits are preserved with recovery INCOMPLETE. Missing/corrupt key does not create a replacement during restoration. Retain recovery records and synthetic before/after evidence.

Required tests precede each corresponding production component. Actual native owner public commit, staged-secret/sanitized-worktree block with scanner witness, public-staged/unstaged-secret success, custom-path/existing-hook exit7/undo/owner edits/flag/restart/effective alternate index controls remain mandatory on the exact new VSIX. No push; F26b separate. Compiler/full/content/affected actual native/withdrawal/source+transition byte barriers still required before next subcard. No rating; original L6 HUMAN-ACTIONS and STOP persists.
