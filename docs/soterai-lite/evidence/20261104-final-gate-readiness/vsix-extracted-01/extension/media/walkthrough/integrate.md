# Secure supported AI tools

SoterAI can find supported local AI client configurations and propose routing them through local checking.

Review every proposed change before it is written. Approved configuration backups are encrypted outside your workspace. **Undo AI Tool Security Changes** offers reviewed recovery; changed ownership or file bytes can prevent restoration. Keep the recovery receipts and review pending changes before removing the extension.

Supported managed traffic routed through SoterAI can be inspected before forwarding. Check each route's Gateway, Vendor-controls-only or Uncovered status. Independent tools and same-user processes can use other paths.
