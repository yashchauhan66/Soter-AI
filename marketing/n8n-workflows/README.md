# 🔥 Soter AI n8n Ultra Workflows

## 🚀 Quick Start Guide

### Step 1: Log into n8n
- Open: http://localhost:5678
- Use your credentials (if you need to reset, re-run the docker container without env vars to set up an owner)

### Step 2: Import Workflows
1. Click **Workflows** > **Import from File**
2. Import **01-bulletproof-ai-customer-support-agent.json**
3. Import **02-secure-autonomous-multi-tool-agent.json**

### Step 3: Configure
1. Add your **Soter AI credentials**
2. Add your **OpenAI credentials** (for Workflow 1)
3. Replace the dummy Slack webhook URLs

## 📦 What’s Included
1. **🛡️ Bulletproof AI Customer Support Agent** – Input/Output guardrails for chatbots
2. **🛡️ Secure Autonomous Multi‑Tool Agent** – Intent verification for agentic workflows
