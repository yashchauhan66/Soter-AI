## FAQ copy

**Does it automatically protect every AI tool?**

No. Local previews help with text you deliberately share. Interception requires
an explicitly configured supported route. Independent uploads and direct file
access are outside the extension's controls.

**Are API keys sent to SoterAI for scanning?**

Local checks and preview generation do not require uploading code to SoterAI.
Configured provider requests and user copy/paste are separate flows; review the
destination's privacy policy.

**Does a clean result mean there are no secrets?**

It means no supported pattern was found within the completed declared scan.
Unknown private prose, unsupported formats and excluded paths need separate
review. Incomplete results must not be treated as clean.

**Does it support macOS, Linux or remote workspaces?**

This candidate targets local Windows x64 workspaces. Other platforms are not
supported by this release.

**Is it open source?**

The included Business Source License applies. Free local use does not establish
an OSI-approved open-source license; refer to the actual license text.
