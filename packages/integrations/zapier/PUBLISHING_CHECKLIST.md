# SoterAI Zapier -- Publishing Checklist

## Prerequisites

- [ ] Node.js 18+ installed
- [ ] Zapier CLI installed (`npm i -g zapier-platform-cli`)
- [ ] Zapier developer account created at https://developer.zapier.com

## Actions to Verify Before Pushing (12)

Version 0.2.0 takes this app from 4 actions to 12, matching the n8n node and the
Make app. Confirm each one appears in `zapier validate` output and returns its
declared `outputFields`:

- [ ] `input_guard` — including the new `primaryRiskType`, `categoryConfidence`, `latencyMs`, and the optional Allowed Topics / System Prompt Context inputs
- [ ] `output_guard` — including the same three calibration fields
- [ ] `pii_redactor`
- [ ] `rag_scanner`
- [ ] `analyze_text` — works with **no** API key; verify that path explicitly
- [ ] `streaming_guard` — check `highestRiskScore` and `firstRiskyChunkIndex` against a multi-chunk sample
- [ ] `universal_guard` — verify a BLOCK on input and a BLOCK on output both surface as `allowed = false`
- [ ] `workflow_audit`
- [ ] `start_agent_session`
- [ ] `agent_action_check` — verify `ASK_APPROVAL` yields `allowed = false`
- [ ] `agent_data_check`
- [ ] `agent_output_check`

## Build and Validate

```bash
npm install
npm run build
npm run validate
```

## Register and Push

```bash
zapier login
zapier register "SoterAI"
zapier push
```

## Promote to Public

```bash
zapier promote <version> public
zapier migrate <old_version> <new_version> --percent 100
```

## Zapier Partner Program

1. Submit app via https://developer.zapier.com
2. Zapier reviews the integration (typical turnaround: 2-4 weeks)
3. Address any review feedback
4. Once approved, the app appears in the Zapier marketplace
