# Protect what you send to AI

Before you paste code or a prompt into ChatGPT, Copilot, Claude, or Cursor, let SoterAI check it first.

- **Scan Current File** — check the file you're working on.
- **Scan Git Diff** — review everything you're about to commit or share.
